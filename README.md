# Remote-Maestro/.github

Fichiers communautaires **par défaut** de l'organisation : ils s'appliquent à tout repo qui ne définit pas
les siens (templates d'issues et de PR, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT).

- `profile/README.md` — page d'accueil publique de l'organisation.
- `workflow-templates/` — workflows proposés dans *Actions → New workflow* de chaque repo.

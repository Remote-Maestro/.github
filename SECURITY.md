# Politique de sécurité

Une télécommande connectée est un point d'entrée vers les équipements du foyer : nous prenons au sérieux
les vulnérabilités (appairage, chiffrement radio, mises à jour OTA, application compagnon).

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.** Utilisez le signalement privé GitHub
(onglet *Security* → *Report a vulnerability*) du repo concerné.

Nous accusons réception sous 5 jours ouvrés et vous tenons informé de la correction.
